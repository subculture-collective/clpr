# Font licences

self-hosted so the app does not depend on a third-party font request.

| `ibm-plex-mono-*.woff2` | IBM Plex Mono, Copyright 2017 IBM Corp., Reserved Font Name "Plex" | SIL Open Font License 1.1 |
